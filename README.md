# OKOLITSA

OKOLITSA is a first-person psychological horror prototype set in a Soviet apartment block surrounded by an endless nocturnal field.

## Current Version

v0.1 Atmosphere Prototype

This build focuses on atmosphere, movement, environment, lighting, sound, and the first playable version of the project space.

## Play

- WebGL prototype: [[itch.io]](https://bubaleh1337.itch.io/okolitsa)
- Windows build: available in GitHub Releases

## Current Features

- Soviet apartment block exterior
- Stairwell and entrance area
- Main apartment visual pass
- First-person movement
- Flashlight
- Door interaction
- Elevator interaction
- Footstep sounds
- Door, elevator, flashlight, and wind audio
- Night lighting and outdoor fog baseline

## Controls

- WASD — Move
- Mouse — Look around
- Shift — Run
- Space — Jump
- E — Interact
- F — Flashlight

## Known Issues

- This is an early prototype, not a complete game.
- There is no main objective yet.
- Visuals and audio are still prototype-level.
- WebGL version is experimental and may not work well on mobile browsers.

## Next Step

The next development goal is to build the first apartment pressure loop: light failure, sound pressure, and domestic horror events.
